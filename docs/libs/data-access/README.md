# data-access

Клиент Nitro API: приложения, версии конфигураций, сохранение и публикация.
Без Angular, без RxJS, без состояния — `fetch` и промисы; Angular-обвязка живёт в приложении.
Контракт снят с боевого Nitro Editor (`docs/nitro3/examples/20-nitro-editor.json`) и
воспроизводится один в один; расхождения — только через владельца API.
Публичная поверхность — `src/index.ts`; спека: `docs/changes/<KEY>/intent.md`.
