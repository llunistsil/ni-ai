# Документация

- `changes/` — изменения: намерение, план, спеки задач; конвенция и жизненный цикл — в
  `changes/README.md`
- `decisions/` — архитектурные решения (ADR): почему выбрано так; критерии, шаблон и
  протокол для агента — в `decisions/README.md`
- `nitro3/` — справочник платформы Nitro3: модель конфига, схема, правила диагностики,
  эталонные примеры. Русский, источник истины для работы с конфигами; не переводить

Правило: знание, которое существует только в чатах или головах, для агента не существует —
приземляйте его сюда. У каждого факта один владелец: прежде чем завести документ, назовите
файл, который этим знанием уже владеет.
