# Промпты стадий

Ровно четыре — по числу стадий процесса: намерение, план, реализация, самопроверка.
Копируются целиком, заполняются плейсхолдеры `<KEY>`, `<slug>`, `<вход>`.

Правила поддержки каталога:

- Один промпт на стадию. Генерические промпты («напиши компонент», «сгенерируй тест»)
  сюда не добавляются — универсальные инструкции живут в `AGENTS.md`, повторяемые
  процедуры — в skills, когда появятся.
- Промпт не пересказывает `AGENTS.md`, README конвенций и `nestor.yml` — только
  стадийные инструкции и ссылки. Один владелец у факта.
- Правка — по правилу двух раз: модель дважды ошиблась так, что пришлось поправлять
  руками, → строка в промпт через MR. Не копить пожелания — фиксировать ошибки.
