# src/studio

Код редактора. Карта папок:

- `document/` — модель конфига без Angular: `selectors/` (чтение), позже `commands/` и
  `diagnostics/`. Правило линтера запрещает здесь `@angular/*`. Почему значение, а не
  классы — `docs/decisions/0001`.
- `state/` — единственное хранилище состояния редактора; компоненты не ходят в `document/`
  напрямую, только через него.
- `shell/` — рамка страницы и шапка.
- `navigation/` — панель: `components-section/` (список компонентов), `tree/` (дерево),
  `panel/` (разделитель, скрытие).
- `fixtures/` — эталонные конфиги; источник — `docs/nitro3/examples`, конвертация в JSON
  один раз, с комментарием об источнике.

Следующий эпик (инспектор) подключается папкой рядом с `navigation/` и читает селекторы
через `state/`. Команды и конвенции — в корневом `AGENTS.md`; здесь их не повторять.
